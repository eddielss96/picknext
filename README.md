# PickNext 點名小幫手

上課點名輔助工具：教授點完一位同學回答後，這位同學要點下一位，並遵守以下規則：

1. 同一個座位表區塊（session）不能連續點兩次（不能在同一區塊內繞圈）。
2. 不能連續點同一性別。
3. 已經被點過的人不能再被點。
4. 點名者必須在 3 秒內決定下一位。

本工具在瀏覽器裡即時算出符合規則的候選人，並用注音標示姓名方便快速唸出。

## 使用方式

1. **座位表設定**：班級名冊（姓名＋性別）已內建在網站裡（`data/roster.json`），第一次開啟網站會自動帶入，不需要手動輸入。之後上傳座位表照片、按「開始自動辨識」，OCR 辨識到的姓名會自動比對名冊校正錯字、直接帶入性別；也可以隨時按「套用名冊校正」重新比對。如果要換成別班的名單，直接在「班級名冊」欄位貼上新的姓名＋性別、按「儲存名冊」覆蓋即可。三個區塊（session）對應座位表中三個倒三角形座位區，是規則1判斷的依據，請確認分區正確。
2. **點名**：課堂上，教授或助教點擊座位表上「剛剛回答的人」，系統會立刻算出下一位建議人選（含注音），照著唸出即可；也可以直接點擊建議清單中任一位。「復原上一步」可修正誤觸，「清除點名記錄」則是開始新的一輪點名。
3. **設定 / 備份**：設定自己的姓名（會在座位表上標示「我」）、匯出/匯入 JSON 備份。所有資料只存在瀏覽器本機（localStorage），換裝置或清除瀏覽器資料前請記得先匯出備份。

## 技術說明

- 純前端靜態網站，可直接部署到 GitHub Pages，不需要任何後端或資料庫。
- 圖片辨識（OCR）使用 [Tesseract.js](https://github.com/naptha/tesseract.js) 搭配繁體中文語言包，只有在「座位表設定」步驟需要網路連線；點名當下（含姓名轉注音）完全是本機運算，不需要網路，也不會把任何資料送到外部伺服器。
- 姓名轉注音使用 [pinyin-pro](https://github.com/zh-lx/pinyin-pro)（中文轉拼音）+ [pinyin-to-zhuyin](https://github.com/logicmason/pinyin-zhuyin)（拼音轉注音符號），兩者皆已內建於 `js/vendor/`，授權見同目錄下的 LICENSE 檔案。

## 部署到 GitHub Pages

1. 把整個 repo push 到 GitHub。
2. 到 repo 的 Settings → Pages，Source 選擇要發布的分支（例如 `main`）與根目錄 `/`。
3. 等待部署完成後，即可用 GitHub 提供的網址開始使用。

## 本機開發 / 測試

不需要建置工具，直接用任何靜態伺服器即可：

```bash
python3 -m http.server 8080
# 開啟 http://127.0.0.1:8080
```
